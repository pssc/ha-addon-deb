# Debian User Terminal

A Debian terminal for Home Assistant with user-focused development tools, including GitHub CLI, Docker CLI, and Python tooling. It inherits the terminal, Ingress support, and configurable WebSocket keepalive from [Debian Base Terminal](../deb/README.md).

Open the app's **Web UI** to use the terminal. See [DOCS.md](DOCS.md) for configuration, included tools, and GitHub CLI sign-in, and [CHANGELOG.md](CHANGELOG.md) for release notes.
